# 网络工程师入门面试经验

> **仓库说明**：本仓库中的所有笔记均由视频教程整理而来——先提取视频字幕，再由 AI 通读字幕、梳理并提取知识点，最终形成结构化笔记。

如果你刚入门或处于求职准备期，建议按下面的主线来准备。以下四条基本覆盖了入门岗位的高频考点，按面试考察的权重排序。

---

## 一、网络基础：CCNP 水平 + CCIE 笔试通过（核心竞争力）

- **定位：最重要，没有之一。** 这是简历和面试中能一眼拉开差距的硬实力。
- **要求：** 具备 CCNP 水平的网络知识储备，并通过 CCIE 笔试。ospf和bgp实验要做熟，面试问的比较多，eigrp是思科私有的很少用
- **时间参考：** 零基础起步，约 **2 个月** 左右。

## 二、Linux 基础操作 + Shell 基础脚本（面试高频）

- 机房里的设备基本都是 Linux 系统，所以 Linux 操作是面试官的高频问题。
- 建议熟练常用基础操作命令，并会编写简单的 Shell 脚本。
- **学习资源：** B 站 **GeekHour** 的「半小时 Linux 教程」和「半小时 Shell 速成」。

## 三、数据中心与服务器基础知识（数据中心方向必看）

- 面试**数据中心**相关岗位时问得较多，其他方向了解个大概即可。
- 花 **两三天** 突击就够：搞懂最基础的几类问题即可——服务器有哪些常见类型、一台服务器由哪些部件组成。
- **学习资源：** **尚诚云课堂** 的数据中心服务器教程。

## 四、Python 基础（面试常问）

- 建议掌握基础，面试中也经常被问到；零基础建议预留约 **1 周**。
- **要求：** 能看懂基础代码逻辑，会 import 并简单使用几个网络方向常用库。
- **学习资源：** **wolf** 的网络工程师 Python 课程。

---

### 小结：准备优先级与节奏

| 学习模块 | 优先级 | 参考时长 | 适用岗位 |
|---|---|---|---|
| CCNP 水平 + CCIE 笔试 | ★★★★★ 核心 | 约 1 个月 | 所有网络岗位 |
| Linux + Shell | ★★★★ 高频 | 配合刷题快速上手 | 所有网络岗位 |
| 数据中心与服务器 | ★★★ 定向 | 2~3 天突击 | 数据中心岗位 |
| Python 基础 | ★★★ 常问 | 约 1 周 | 网络自动化/运维方向 |
